## Function

Obtains the value of the *idx*-th dimension of the original shape.

## Function Prototype

```cpp
int64_t GetOriginShapeDim(const size_t idx) const
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|idx|Input|Index of the dimension, starting from 0.|

## Return Value

Returns the value at the **idx** position of the original shape.
