## Function

Sets the descriptor (**TensorDesc**) of a tensor.

## Function Prototype

```cpp
graphStatus SetTensorDesc(const TensorDesc &tensor_desc)
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|tensor_desc|Input|Tensor descriptor to be set.|

## Return Value

**graphStatus** type: Returns **GRAPH\_SUCCESS** on success; otherwise, returns **GRAPH\_FAILED**.
