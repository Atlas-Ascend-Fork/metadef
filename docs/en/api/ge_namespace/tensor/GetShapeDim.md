## Function

Obtains the **idx**-th dimension of a shape.

## Function Prototype

```cpp
int64_t GetShapeDim(const size_t idx) const
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|idx|Input|Index of the dimension, starting from 0.|

## Return Value

Returns the value at the **idx** position of the shape, with a default value of **0**.

## Exception Handling

None

## Constraints
