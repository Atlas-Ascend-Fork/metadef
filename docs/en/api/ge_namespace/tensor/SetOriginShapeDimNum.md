## Function

Sets the dimension size of the original shape, that is, the rank size.

## Function Prototype

```cpp
graphStatus SetOriginShapeDimNum(const size_t dim_num)
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|**dim_num**|Input|Dimension size of the original shape, that is, the rank of the original shape.|

## Return Value

**graphStatus** type: Returns **GRAPH_SUCCESS** on success; otherwise, returns **GRAPH_FAILED**.

## Exception Handling

None

## Constraints

None
