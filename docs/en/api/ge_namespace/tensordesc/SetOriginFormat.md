## Function

Sets the original format of a tensor in **TensorDesc**.

This format refers to the format of the original network model.

## Function Prototype

```cpp
void SetOriginFormat(Format origin_format)
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|origin_format|Input|Original format information to be set. For the definition of the **Format** data type, see **Format**.|

## Return Value

None
