## Function

Obtains the original **Format** of the tensor described by **TensorDesc**.

This **Format** refers to the format of the original network model.

## Function Prototype

```cpp
Format GetOriginFormat() const
```

## Parameters

None

## Return Value

Returns the **originFormat** information of the tensor described by **TensorDesc**.

For the definition of the **Format** data type, see [Format](../Format.md).
