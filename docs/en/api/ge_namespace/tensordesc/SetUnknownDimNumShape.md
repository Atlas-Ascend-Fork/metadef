## Function

Sets the shape of the tensor to \{-2\}, indicating that the tensor is completely unknown.

## Function Prototype

```cpp
graphStatus SetUnknownDimNumShape()
```

## Parameters

None

## Return Value

**graphStatus** type: On success, the value is **GRAPH\_SUCCESS** (that is, **0**); other values indicate a failure.
