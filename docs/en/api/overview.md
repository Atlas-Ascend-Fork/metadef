# List of Basic Data Structures and APIs

This document provides the basic data structures and APIs that are relied upon during operator development and graph development, categorized as follows:

- **ge** (Graph Engine) namespace

    **ge** represents a general-purpose namespace focused on graph construction and graph compilation. This namespace provides an extensive set of APIs for building and managing complex graph structures. Its core strengths lie in its generality and flexibility, enabling it to meet various graph processing requirements, whether during the design phase or the compilation process.

- **gert** (GE Runtime) namespace

    **gert** is a namespace specifically designed for the runtime environment and provides a series of high-performance data structures to ensure optimal performance during execution.

- C APIs

    C language APIs for operator and graph development.
