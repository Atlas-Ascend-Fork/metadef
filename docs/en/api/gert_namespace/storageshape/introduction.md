This class describes the shape of a tensor, including two pieces of information: **origin\_shape** and **storage\_shape**. **origin\_shape** represents the mathematical description of the tensor shape, and **storage\_shape** represents the shape format of **origin\_shape** at runtime.

## Header File to Include

```cpp
#include <storage_shape.h>
```
