# Inputs

## Function

Sets the input pointer of the **values** of **Context**. The type carried by **values** is a **void\***  pointer array.

## Function Prototype

```cpp
OpKernelContextBuilder &Inputs(std::vector<void *> inputs)
```

## Parameters

|Parameter|Input/Output|Description|
|--|--|--|
|inputs|Input|Input pointer array. Ownership is managed by the caller, who must ensure that the lifetime of the input pointers is longer than that of the **ContextHolder** object generated by **Build**.|

## Return Value

**OpKernelContextBuilder** object, which is used for chained calls.

## Constraints

This API must be called before the **Build** method is called; otherwise, the constructed **KernelContext** will contain undefined data.
