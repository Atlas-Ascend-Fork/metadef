The **Range** class describes the lower and upper bounds of an object and contains two pieces of information:

```cpp
T *min_;
T *max_;
```

**min_** is a pointer to the lower bound of the object, and **max_** is a pointer to the upper bound of the object. Users can define the types of the lower and upper bounds themselves.

## Header Files to Include

```cpp
#include <range.h>
```
