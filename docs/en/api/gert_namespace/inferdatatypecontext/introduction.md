**InferDataTypeContext** is derived from **ExtendedKernelContext** and is a context class used for data type (**DataType**) inference. Its main purpose is to provide APIs for obtaining input and output data types during operator data type inference, and to support setting the output data type.

The inheritance diagram of **InferDataTypeContext** is as follows:

![inferdatatype_context](../../figures/inferdatatype_context.png)

## Header File to Include

```cpp
#include <infer_datatype_context.h>
```
