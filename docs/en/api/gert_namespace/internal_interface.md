# Internal Associated APIs

<!-- md-trans-meta sourceCommit=7ba7d1f270370e0de2d9099271255419dd4c1b21 translatedAt=2026-10-09T02:22:16.255Z pushedAt=2026-10-15T03:48:04.789Z -->

During operator prototype registration, tiling implementation, and shape inference, the external open APIs that are used internally call some auxiliary data structures and APIs, which are referred to as **internal associated APIs**. Developers do not directly call internal associated APIs; they are only briefly introduced here.

## KernelContext Class

This class is a wrapper of the underlying data structure **KernelRunContext**. It contains the operator input and output count information required for kernel execution, as well as the input and output data information, **compute\_node\_info**, and **kernel\_extend\_info**.

**Table 1** KernelContext class member functions

|API|Function|
|--|--|
|GetInput|Obtains the pointer to the input **Chain**. **Chain** is a class that can be used to store data of any type.|
|GetInputNum|Obtains the number of kernel inputs.|
|GetInputPointer|Obtains the pointer to the input data. This function first obtains the input **Chain**, then obtains the pointer from the input **Chain**.|
|GetInputStrPointer|Obtains the pointer to the input string. This function first obtains the input **Chain**, then obtains the pointer from the input **Chain**.|
|GetInputValue|Obtains the value of the input data. This function first obtains the input **Chain**, then obtains the value from the input **Chain**.|
|GetOutput|Obtains the pointer to the output **Chain**.|
|GetOutput2|Obtains the pointer to the output **Chain**.|
|GetOutputNum|Obtains the number of kernel outputs.|
|GetOutputPointer|Obtains the pointer to the output data. This function first obtains the output **Chain**, then obtains the pointer from the **Chain**.|
|GetContext|Obtains the underlying context structure.|
|GetKernelExtend|Obtains the pointer to the kernel extension information.|
|GetComputeNodeExtend|Obtains the pointer to the compute node information.|
|MutableInput|Obtains the pointer to the input **Chain**.|
|MutableInputPointer|Obtains the pointer to the input data. This function first obtains the input **Chain**, then obtains the pointer from the input **Chain**.|
|IsInlineSize|Checks whether a piece of data is stored inline based on its length. Inline storage means that the data does not require separate memory allocation when stored in the context.|

## Chain Class

**Chain** is a class that can be used to store data of any type. Data is stored through its **Set** API and retrieved through the **GetPointer** or **GetValue** method.

**Table 3** Chain class member functions

|API|Function|
|--|--|
|GetPointer|Obtains the pointer to the data stored in **Chain**.|
|GetValue|Obtains the value of the data stored in **Chain**.|
|Set|Sets data into **Chain**. When setting a data pointer, it attempts to call the deleter to delete the data previously stored in **Chain**.|
|SetWithDefaultDeleter|Sets data into **Chain**. When setting a data pointer, it attempts to call the deleter to delete the data previously stored in **Chain**.|
|HasDeleter|Checks whether the data currently stored in **Chain** has a deleter.|

## ContinuousBuffer Class

The **ContinuousBuffer** class is used to continuously store data of any type. Each piece of data is converted into a **uint8\_t** array for storage, and each storage unit is called a buffer. **ContinuousBuffer** uses two attributes to describe the stored data: the number of stored buffers and the memory offset corresponding to each buffer **offsets\_**. Each buffer is contiguous in memory.

**Table 4**  ContinuousBuffer class member functions

|API|Function|
|--|--|
|GetNum|Obtains the number of buffers.|
|GetTotalLength|Obtains the total length of this instance.|
|Get|Obtains the buffer pointer and length information.|

## KernelExtendInfo Class

This class is used to store additional information about the kernel at runtime, including the kernel name, type, the index of the kernel type used for profiling registration, and the index of the compute node name.

**Table 5**  KernelExtendInfo class member functions

|API|Function|
|--|--|
|GetKernelName|Obtains the kernel name.|
|SetKernelName|Sets the kernel name.|
|GetKernelType|Obtains the kernel type. One operator can correspond to multiple kernels, and thus correspond to multiple kernel types.|
|SetKernelType|Sets the kernel type.|
|SetKernelTypeIdx|Sets **kernel_type_idx_**, used for profiling. During profiling, the **idx** corresponding to the kernel type string is set, and the **idx** is used instead of the kernel type string as the identifier to improve speed.|
|SetNodeNameIdx|Sets **compute_node_name_idx_**, used for profiling. During profiling, the **idx** is used instead of the node name string as the identifier to improve speed.|
|GetNodeNameIdx|Obtains **compute_node_name_idx_**, used for profiling.|
|GetKernelTypeIdx|Obtains **kernel_type_idx_**, used for profiling.|
