This class is a POD class that stores the description information and the actual data elements in a contiguous memory space, with the element type being the **ContinuousVector** structure. It does not support dynamic expansion.

The description information of this class includes the maximum number of elements that can be stored and the actual number of elements currently stored.

## Required Header Files

```cpp
#include <continuous_vector.h>
```
