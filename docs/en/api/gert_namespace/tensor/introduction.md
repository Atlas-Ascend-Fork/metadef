**Tensor** is a tensor management class used to store and manipulate tensor data. This class records the tensor's **shape**, **data format**, **data type**, and **storage location**, and provides APIs such as data address access and data size calculation.

## Header File to Include

```cpp
#include <tensor.h>
```
